#Employee Management System (EMS)

The Employee Management System (EMS) is a web app built using React + Vite that helps organizations handle employees and their tasks in a simple way.
It comes with two different dashboards – one for Admins to manage employees and tasks, and one for Employees to track and update their work.

#Working for this projects
-Provides a login system for Admin and Employees.
-Displays separate dashboards for Admin and Employee based on role.
-Allows Admin to create and assign tasks to employees.
-Lets Employees view tasks assigned to them.
-Enables Employees to accept, complete, or fail a task.
-Updates task status automatically (New → Accepted → Completed/Failed).
-Shows task statistics (number of new, accepted, completed, failed tasks).
-Stores user and task data in LocalStorage for persistence.
-Provides a simple, responsive interface for easy navigation.
